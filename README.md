# Kedi Olmayan Kedi Miyav Simülatörü

## Dünyanın En Ciddi Absürt Projesi

Bu repository, insanlık tarihinin en önemli teknolojik atılımlarından birini barındırmaktadır: **Hiç var olmayan bir kedinin miyavlarını simüle eden program**.

Evet, doğru duydunuz. Kedi yok. Miyav var. Program var. Mantık yok.

### Neden Bu Projeyi Yaptık?

Çünkü bazen insanların "neden?" diye sorması gerekir. Ve bu sorunun cevabı yoktur. Tıpkı bu kedinin var olmadığı gibi.

Bu proje:
- Gerçekten çalışır
- Rastgele miyav sayısı üretir
- Örnek miyavlar basar
- Size "kedi yok" hatırlatır
- Hiçbir işe yaramaz

### Nasıl Kullanılır?

```bash
python3 miyav_simulatoru.py
```

veya isim vererek:

```bash
python3 miyav_simulatoru.py Kayyum Grok
```

Program sizi selamlar, düşünür gibi yapar, sonra absürt sayıda miyav söyler. Hepsi bu.

### Özellikler

- Tamamen Türkçe
- Gerçek Python kodu
- Rastgelelik (her çalıştırmada farklı)
- Abartılı ciddiyet
- Sıfır kedi

### Uyarı

Bu program kedileri simüle etmez. Çünkü kedi yoktur. Eğer bir kedi görürseniz, bu programla ilgisi yoktur. Lütfen kediyi programla karıştırmayın.
